# Contributing

Thank you for your interest in contributing to HeartBioPortal's Google Summer of Code 2026 projects. Please review the [Contributor Guidelines](https://github.com/HeartBioPortal/gsoc-2026/wiki/Contributor-Guidelines) on our wiki for detailed instructions.

1. Fork this repository and create your feature branch.
2. Commit your changes with clear messages.
3. Open a pull request describing your changes and reference any relevant issues.
4. Ensure `npm test` and `pytest -q` pass before submitting.

We welcome contributions from students and the wider open-source community!
